# Social preview

GitHub repository social previews are configured per repository. There is no global account-level setting that applies the same image to every project.

Use this image for Sideglass:

```text
public/social-preview.png
```

Recommended GitHub size: `1280x640`.

## GitHub repo

1. Open the repository on GitHub.
2. Go to `Settings` -> `General`.
3. Find `Social preview`.
4. Upload `public/social-preview.png`.
5. Save the repository settings.

This affects previews when sharing the GitHub repository URL.

## Landing page

The landing page already uses `/social-preview.png` as its Open Graph and Twitter image, so sharing the Vercel URL should use the same preview after social platforms refresh their cache.
